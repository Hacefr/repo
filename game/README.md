> **Play online with a friend right now at [pvzo.onrender.com](https://pvzo.onrender.com)!**

### What is this?
This is a **dedicated online multiplayer co-op mod** built on top of the open-source HTML5 port of Plants vs. Zombies. It features real-time plant synchronization, shared sun economies with multipliers, live colored teammate cursors, anti-griefing shovels, and true endless co-op survival waves!

* Looking for the full single-player campaign, adventure mode, and minigames? Head over to the official home of the single-player port: [pvzm.net](https://pvzm.net).
